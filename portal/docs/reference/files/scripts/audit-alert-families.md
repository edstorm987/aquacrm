# `scripts/audit-alert-families.ts`

← [File index](../../files-index.md) · Area: Scripts — scripts/

**What it is:** Every declared alert family, exercised — not just the ones that happen to fire on today's data. The live audit only proves what the current records raise. A family that never fires here can still be broken: no focus, no clearance, no evidence, a Resolve button pointing nowhere. This walks the whole catalogue and asks the same questions of each.
