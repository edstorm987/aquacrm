# Milesymedia Portal

Standalone portal app for local development and Vercel.

## Local

```bash
npm install --legacy-peer-deps
npm run dev
```

Open:

- http://localhost:3032
- http://localhost:3032/login?next=/portal
- http://localhost:3032/dev/pov

## Vercel

Import this folder as its own Vercel project:

```text
04-milesymedia-portal/milesymedia-portal
```

The public Milesymedia website is intentionally not mounted in this app.
