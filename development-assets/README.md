# Development Assets

Canonical source files for the Milesymedia Development toolkit.

## Folders

- `inspiration/`: saved screenshots and visual references catalogued in Development > Toolkit.
- `branding/`: future logos, palettes, font files and brand guidelines.
- `imports/`: future structured exports that should be reviewed before cataloguing.

Run `pnpm run catalogue:development` from `portal/` after adding files. The catalogue stores searchable metadata and retains these files as the source of truth.
